# 内存成本模型（A13）

论文式 (3)–(5) 把 `M_batch`、`M_df` 当作硬件无关常数，但未给出数值。

- URGE 主配置仍使用 **slot 单位** `m_batch=1`、`m_frame=1`（与已跑通的开发控制器一致），不把 GPU MiB 斜率静默塞进式 (3)/(4)。
- `profile_costs` 在真实 train-step 上对 `cat(new,replay)` 配对测量 GPU allocator peak，并用 held-out 配对报告 MAPE；host 侧用 uint8 帧 RSS 增量对照 `3*32*32` 并报告 MAE。`complete=true` 表示**已有实测误差**，不表示 host 硬限制或 Jetson 模型可用。
- 2026-09-14 实测：device held-out MAPE≈0.40%；host frame RSS MAE≈1.0 MiB（相对 3072 B/帧的线性模型误差很大，WSL RSS 噪声大，不能当 cgroup 上限）。
- `plugin_gem_ewc_bytes` 仍是 EWC 副本 + 50 张 GEM 帧的分配增量，不是完整插件训练循环。
- 不得把本机斜率当成 Jetson 系数，也不得把 slot 控制器轨迹改写成“已用真实 MiB 控制”。
