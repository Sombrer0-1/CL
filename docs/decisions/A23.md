# A23 GSS × MAX-P 当 batch > mem_size

分类：`source_inferred` / 平台适配。官方 Avalanche 0.6 GSS 在 `occupied // batch == 0` 时对空的 `mem_grads` 做 `max()`，并且 `multinomial(..., batch, replacement=False)` 要求 buffer ≥ batch。论文 MAX-P 重建为 batch=256、replay=10，触发该假设。

采用行为：buffer 已满且 occupancy < batch 时，只用前 `occupancy` 个新样本做 GSS 打分与替换；内存子集大小为 `min(batch, occupancy)`，至少 1 个 subset。首批插入分数全为 0.1 时官方 min-max 后 multinomial 权和为 0，改为均匀分布。不把该格标成未实现。空 buffer 不打分。


验证：`tests/test_gem_agem_gss.py::test_gss_full_buffer_when_batch_exceeds_mem_size`。E04 GSS MAX-P 在此修复后重跑；修复前 `implementation_error` 记录保留。
