# 基线重建（A11）

论文只给出 MAX-A / MAX-P / LR / Oracle 的文字，没有 batch/replay/插件超参数。本仓库全部使用 `_reconstructed` 后缀。

| method_id | 开发采用值 | 依据 |
|---|---|---|
| `max_a_reconstructed` | batch=1, replay=200, GEM+EWC 常开 | Avalanche 默认 batch/replay；Table 1 高级插件 |
| `max_p_reconstructed` | batch=256, replay=10 | Oracle 网格中的大 batch × 最小 replay；开发吞吐起点 |
| `lr_reconstructed` | layer2 latent, freeze lower after exp0, mem=200 | Pellegrini/AR1 适配 ResNet-20 |
| `oracle_reconstructed` | 42 组网格见 `python -m orion_repro.oracle_grid` | 论文 §5.1；选择规则 A15 |

正式主表不得去掉 `_reconstructed`，除非获得作者配置证据。
