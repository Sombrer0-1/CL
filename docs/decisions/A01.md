# A01 框架版本与 GSS 兼容补丁

- Avalanche 论文未给版本。锁定使用 `avalanche-lib==0.6.0`，先装 `torch==2.14.0+cu130` 再 `--no-deps` 安装，避免覆盖 CUDA 轮子。
- `avalanche` 顶层 import 需要 `wandb`（confusion_matrix.py），因此额外安装 wandb，运行时 `WANDB_MODE=disabled`。
- GSS：`GSS_greedyPlugin` 在 `mem_strength` 为 float 时执行 `torch.zeros(1.0, dim)`，PyTorch 2.14 报 `zeros() takes 1 positional argument but 2 were given`。补丁将 `mem_strength` 转为 int。见 `src/orion_repro/strategies/gss_compat.py`。不改变 GSS 选样语义。
- 验证配置：`configs/smoke_gss.yaml`；完整数值与选择行为仍需专项验收。
