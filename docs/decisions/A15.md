# A15 Oracle 选择规则

> 历史协议/选择规则参考。当前实验范围与新有限搜索规则由 PLAN.md 和 light24_v1.md 规定；不要据此恢复旧全矩阵。
论文 §5.1 只说对 batch×replay 的 42 格做 brute-force 以覆盖 P 和 S，没有标量目标。

**冻结规则（开发 val，model seed=0，split seed=17）：**

1. 只保留 `status=completed` 且 `timing_schema=online_loop_v2` 的格子。
2. 在 `(P_diag, S_initial, learning_s)` 上构造 Pareto（最大化 P、S，最小化 learning_s）。
3. 在 Pareto 上选 `0.5 P_diag + 0.5 S_initial` 最大者。
4. 并列则更短 `learning_s`，再更小峰值 device 分配，再 `oracle_cell_id` 字典序。
5. 同时报告 P-best、S-best 与 Pareto 全集，不把单一格子说成论文 Oracle。
6. 获选配置再在 `paper_feedback_diag_initial_v1` 下用 seeds 0/1/2 重跑。不在正式测试上重选。
7. 搜索总墙时与获选配置单次训练墙时分账。

旧 CIFAR10 42 格若早于峰值读取修复或 `legacy_includes_setup`，其内存列与控制轨迹不得直接当当前实现证据；训练语义是否可复用须按 identity 核对。
