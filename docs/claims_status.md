# 当前结论状态

更新：2026-09-14，light24_v1 全部 96 格执行完毕（90 completed + 6 个 128MiB 启动 OOM 资源失败）。逐项证据见 reports/light24/RESULTS.md；下表为判定摘要。历史 71 次运行仍只作背景，不并入本表判定。

| 命题 | 当前判定 | 本轮证据与边界 |
|---|---|---|
| C01 参数/插件权衡 | 部分支持 | batch/replay 方向证据强（b256 摧毁 P_diag、r2000 稳定抬 S）；插件维度未激活，无证据；6 格/场景，r2000 为边界值 |
| C02 自适应机制有效 | 不支持（本范围） | URGE 峰值 0.006 < 最低受试阈值 0.025；optimizer/插件从未切换；完整 Orion ≈ 初始资源静态 ER。非证明机制在受限设备无效：本平台延迟/显存均远离 sigmoid 激活区 |
| C03 跨场景方法权衡 | 部分支持 | 两场景方向一致（同资源 Orion≈静态；搜索静态占优 (P+S)/2）；CORe50 有小幅 P↑S↓ 衰减效应；不外推五基准全集 |
| C04 多算法普适性 | 未验证（范围外） | 本轮不扩展；历史 ER/GEM/AGEM/GSS 证据及 GSS 崩塌保留为限定背景 |
| C05 用户偏好 | 不支持（本范围） | 权重实现改变 URGE 数值但无任何行为/指标分化；偏好表达依赖控制器触发，本负载下不发生 |
| C06 内存预算 | 部分支持 | allocator 配额真实生效并给出可行边界（峰值 125–129MiB；128MiB 两方法全部启动 OOM 并保留）；256/512MiB 质量与 core 一致；Orion 无预算适应优势；allocator ≠ host/全 GPU 硬限制 |
| C07 统一预取 | 部分支持（语义）/不支持（收益） | 逐 seed dP=dS=0、访问计数全等的严格等价；开启后 +31–44% online 时间（每批包装开销，等待~0）；仅静态轨迹 |
| C08 系统开销 | 支持（限定） | 控制器+重配置 <0.01s/运行；评价占 online 16%/39%（CIFAR100/CORe50）；RSS ~2GB、swap 60–93MiB；分项口径见 overhead.csv |

判定用支持、部分支持、不支持、未验证；每条结论的适用范围与局限见 RESULTS.md §5。Endless 为开发划分辅助证据，其 IC 时间差异经重跑探针证伪为主机计时方差。
